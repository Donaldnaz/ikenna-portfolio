### Focus
Containerized services, API communication, scalable AI deployment, service isolation, CI/CD, observability, cloud storage integration.

### Tools
- **Containers:** Docker, Kubernetes
- **Backend:** FastAPI
- **Cloud:** Cloud Run, ECR, Artifact Registry
- **Infrastructure:** Terraform
- **CI/CD:** GitHub Actions

I developed a microservice-based architecture to host and scale AI workloads efficiently. Each service was containerized using Docker and orchestrated via Kubernetes (or Cloud Run), ensuring isolation and independent scalability. The system integrated seamlessly with cloud storage and used GitHub Actions for automated deployment and testing.
