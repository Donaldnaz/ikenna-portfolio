### Focus
Cloud events, async workflows, serverless triggers, Pub/Sub or EventBridge, automated file processing, retries, logging.

### Tools
- **Cloud:** GCP, AWS
- **Messaging:** Pub/Sub, EventBridge
- **Serverless:** Cloud Functions, Lambda
- **Storage:** Cloud Storage, S3
- **Infrastructure:** Terraform

This project involved building a highly scalable event-driven system to handle automated file processing and asynchronous workflows. By leveraging serverless triggers and managed event buses, I created a resilient system capable of handling spikes in traffic with built-in retry logic and comprehensive logging.
